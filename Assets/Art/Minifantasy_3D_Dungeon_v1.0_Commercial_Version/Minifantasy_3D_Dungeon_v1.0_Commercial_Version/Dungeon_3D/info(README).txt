+ Floor, walls and ceiling pieces should line up properly on a 1x1x1 meter grid.


+ Props should be used outside of the grid to more easily fine tune placement.


+ The light on torches and candles are billboard animated sprites placed on top of the model. The sprite sheets have been adjusted to an odd number of pixels to more easily center them on the model.

-Frame size
Candle: 7x8px
Torch: 15x15px

-Frame Duration
200ms


+ Character sprites included with the intent for them to be used as animated billboard sprite characters

- Frame size
32x32px for all the animations.

- Frame Duration
100ms: Attack, Jump, Die and Dmg.
200ms: Idle and Walk.


+ Demo scenes are available in the /obj folder.


+ This asset pack was created with Crocotile. Crocotile 3D files are available in the /Source folder.
